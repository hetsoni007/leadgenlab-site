29 Sep 2026 · Pro 500 + Astra Ultrafast

A premium plan adds a faster service tier for GPT-6 Astra.

OpenAI says its Pro 500 plan includes Astra Ultrafast for ChatGPT Work and Codex. The tier is $500/month and web-only at launch. This is a high-cost plan change, not a feature most casual users need to act on.

Technical detail and source

Ultrafast draws on the included allowance first, then the credit balance. OpenAI says credits on Pro 100 or Pro 200 do not unlock the Ultrafast tier. Confirm current plan conditions before procurement.

Claude Sonnet 5.5

Newest model release
A speed and cost claim worth measuringNew model

Anthropic positions Sonnet 5.5 as a faster, lower-cost upgrade for everyday work.

In simple terms

Think of a model as a capable assistant. Anthropic says this one handles most work faster and uses less task cost than its previous Sonnet 5. That might matter if you repeat similar jobs often.

For technical readers

Anthropic reports 30%+ higher speed and up to 30% lower cost per task for most work versus Sonnet 5. Treat both as vendor-reported comparisons; prompt, output length, tools, workload, and usage settings can change observed results.

A useful first test: pick one recurring task, run the same inputs on both versions where available, and compare output quality, elapsed time, correction effort, and actual billable usage.
